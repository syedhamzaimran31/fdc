# Skyline Residences — Lead Landing Page (starter)

A Next.js (App Router) landing page for an off-plan property project. The team
started it and left it unfinished. Your task is to pick it up.

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## What's in here

- `app/page.js` — the landing page
- `components/LeadForm.js` — the lead capture form
- `app/api/lead/route.js` — the endpoint the form submits to
- `lib/leads.js` and `data/leads.json` — a simple file-based lead store (fine for this task, no database needed)

## What's left to do

The short version, full instructions are in your task brief:

1. Finish the lead form so a submitted lead is captured and the user sees a proper success state.
2. Add a **budget range** field to the form and make sure it is saved with the lead.
3. Leave the code in a state you would be happy to hand to a teammate.

Keep the scope tight, and use whatever tools you normally would.
